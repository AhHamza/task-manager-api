# Task Manager App

A RESTful API for managing user tasks with secure authentication.

## Technologies
- Node.js, Express, MongoDB
- JWT for authentication
- SendGrid for task reminders

## Key Features
- User registration and login
- CRUD operations for tasks
- Data validation and error handling
- RESTful API endpoints
- Task reminders via SendGrid
- Testing with Jest

## What I Learned
- Implemented backend for a task manager application following a structured course.
- Used an AI-generated frontend prototype to demonstrate API functionality.
- Learned secure authentication and authorization workflows using JWT.
- Designed RESTful endpoints and worked with MongoDB.
- Applied data validation and error handling for APIs.
- Implemented automated testing with Jest.
